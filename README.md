# 🧾 InvoiceSync  
**Générez vos factures. Suivez votre comptabilité. Gagnez du temps.**

InvoiceSync est une application moderne destinée aux **entrepreneurs**, **freelances** et **petites entreprises**.  
Elle permet de **générer des factures professionnelles**, de **gérer sa comptabilité** simplement et d’automatiser plusieurs tâches administratives chronophages.

Développée avec :  
- **Back-end :** C# / .NET  
- **Front-end :** React + TypeScript  
- **Base de données :** (à préciser : SQL Server / PostgreSQL / autre)

---

## 🚀 Fonctionnalités principales

### 💼 Gestion des factures
- Création, édition et suppression de factures  
- Export PDF  
- Numérotation automatique  
- Gestion des statuts (Payée, En attente, En retard)

### 👥 Gestion des clients
- Ajout et suivi des informations clients  
- Historique des factures par client  
- Notes internes

### 📊 Tableau de bord comptable
- Vue d’ensemble des revenus  
- Statistiques mensuelles et annuelles  
- Graphiques (CA, paiements, retards)

### ⚙️ Automatisations et utilitaires
- Préremplissage des données récurrentes  
- Calcul automatique de la TVA  
- Génération de devis (en option)
